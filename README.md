## RGC syntax for GNU nano

Copy `rgc.nanorc` to `~/.config/nano/` (or `/etc/nanorc/` for system-wide) and add this line to your `nanorc`:

```
include "~/.config/nano/rgc.nanorc"
```

Then open a `.rg` file and syntax highlighting is active automatically.
